# Archived work

The presentation and its supporting models are the main project in `CSC410Pres/`.
This folder preserves work that would otherwise distract from that classroom story.

- `early-experiments/`: the older scripts, datasets, saved models and plots formerly loose in the repository root. Original script contents are unchanged. Its original dependency file and README are retained there.
- `portfolio-expansion/`: the later PyTorch, tuning, tracking, SHAP, audit, API, Docker and testing additions, with all saved predictions and evidence. These additions were separate from the supplied classroom presentation.
- `root_duplicates/`: unchanged copies of data archived during the earlier cleanup. Relative compatibility links keep the old experiments' input paths intact.
- `duplicate_manifest.json` and `submodules.json`: historical records of the earlier file locations and missing source checkouts.

Archived results are retained as evidence, not relabeled as work from the presentation.
The missing-source placeholder folders live with the early experiments; their unavailable data was never recovered.
